📖 Три типа III склонения
Общий признак III склонения: Gen. sing. = -is. Тип склонения определяется по основе и окончанию Nom. sing.

📌 Гласный тип
К гласному типу относятся только существительные среднего рода с окончанием в Nom. sing.: -e, -al, -ar.

Примеры

  • rete, retis, n — сеть
  • animal, animalis, n — животное
  • calcar, calcaris, n — шпора

Ключевые окончания

  • Nom. plur. → -ia
  • Gen. plur. → -ium
  • Abl. sing. → -i

Образец: animal, animalis, n — животное

📌 Смешанный тип

Группа 1: Равносложные

Одинаковое количество слогов в Nom. и Gen. sing., окончания -es, -is.

  • auris, is, f — ухо
  • basis, is, f — основание
  • canalis, is, m — канал

Группа 2: Основа на несколько согласных

  • dens, dentis, m — зуб (dent-)
  • pars, partis, f — часть (part-)
  • pons, pontis, m — мост (pont-)
NB! Главное отличие от согласного типа: Gen. plur. → -ium (вместо -um).

Образец 1: auris, is, f — ухо
