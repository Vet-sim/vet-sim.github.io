1. Что такое конструктор тестов

Конструктор тестов — это инструмент для создания интерактивных проверочных заданий. Он решает несколько задач преподавателя:

  • Проверка знаний — автоматическая оценка ответов студента.
  • Разные форматы — одиночный и множественный выбор, текстовый ответ, сопоставление.
  • Работа с изображениями — вопросы по схемам, снимкам, препаратам с метками.
  • Гибкость — настройка времени, проходного балла, перемешивания.
  • Автономность — готовый HTML-файл работает без интернета.

2. Интерфейс и вкладки

Конструктор состоит из трёх вкладок и шапки с кнопками управления:

Элемент Что находится Действия
Шапка Кнопки «Новый», «JSON», «Загрузить», «Экспорт HTML», «Просмотр» Сохранение, загрузка, экспорт, предпросмотр
Вкладка «⚙️ Настройки» Название, описание, дисциплина, автор, время, балл, чекбоксы Заполнение параметров теста
Вкладка «📋 Вопросы» Список вопросов и редактор Добавление, редактирование, удаление, перемещение вопросов
Вкладка «👁️ Предпросмотр» Тест глазами студента Проверка перед экспортом
📌 Важно: Все изменения автоматически сохраняются в браузере (localStorage). Если закрыть страницу и вернуться — тест восстановится.

3. Основные настройки теста

На вкладке «⚙️ Настройки» задаются базовые параметры:

3.1 Обязательные поля

  • Название теста — отображается студенту в шапке.
  • Описание / инструкция — что студент увидит на стартовом экране.
  • Дисциплина — выбирается из списка (Анатомия, Фармакология, Хирургия и др.).
  • Автор — ваше ФИО (по желанию).

3.2 Параметры оценивания

  • Время, мин — ограничение по времени. 0 = без ограничения.
  • Проходной балл, % — минимальный процент для зачёта (по умолчанию 70%).

3.3 Дополнительные опции

  • Перемешивать вопросы — каждому студенту вопросы идут в случайном порядке.
  • Перемешивать варианты ответов — варианты внутри вопроса тоже перемешиваются.
  • Показывать правильный ответ после каждого вопроса — если включено, студент сразу после ответа на вопрос видит, правильно ли он ответил, и какой ответ был верным. Если выключено — проверка происходит только в конце теста.
💡 Совет: Для контрольных работ включайте оба перемешивания — это снижает списывание. Для тренировочных тестов лучше выключить, чтобы студент запоминал порядок. Опцию «Показывать правильный ответ» включайте для обучающих тестов и выключайте для экзаменационных.

4. Типы вопросов

Конструктор поддерживает четыре типа вопросов. Перед добавлением выберите тип в выпадающем списке рядом с кнопкой «➕ Добавить вопрос».

4.1 Одиночный Одиночный выбор

Студент выбирает один правильный вариант из нескольких. Классический формат теста.

  • Минимум 2 варианта ответа.
  • Отмечается один правильный (радиокнопка).

4.2 Множественный Множественный выбор

Студент выбирает несколько правильных вариантов. Подходит для вопросов вида «Выберите все симптомы…».

  • Минимум 2 варианта ответа.
  • Отмечается один или несколько правильных (чекбоксы).
  • Ответ засчитывается, только если выбраны все правильные и ни одного лишнего.

4.3 Текстовый Текстовый ответ

Студент вводит ответ вручную. Подходит для терминов, названий, чисел.

  • Правильный ответ задаётся в поле, несколько вариантов — через |.
  • Пример: hepar|heparis|печень — засчитается любой из трёх вариантов.
  • Регистр и знаки препинания не учитываются.
  • Буква «ё» приравнивается к «е».

4.4 Сопоставление Сопоставление

Студент сопоставляет элементы левой колонки с правой. Подходит для «термин → определение», «препарат → механизм действия».

  • Минимум 2 пары.
  • Левая часть — фиксированная, правая выбирается из выпадающего списка.
  • Ответ засчитывается, если все пары сопоставлены верно.
📘 Примеры по типам

Одиночный: «Сколько камер в сердце КРС?» → 4
Множественный: «Выберите жвачных животных» → КРС, овца, коза
Текстовый: «Название самой крупной кости собаки» → бедренная
Сопоставление: Амоксициллин → β-лактам, Гентамицин → аминогликозид

5. Изображения и метки

К любому вопросу можно прикрепить изображение и расставить на нём нумерованные метки. Это идеально для вопросов по анатомии, рентгенологии, гистологии.

5.1 Как добавить изображение

  1. В редакторе вопроса найдите поле «Изображение».
  2. Нажмите на кнопку выбора файла, выберите картинку (JPG, PNG).
  3. Изображение отобразится в блоке ниже.

5.2 Как расставить метки

  1. Кликните по изображению в нужном месте — появится круглая метка с номером 1.
  2. Повторные клики добавляют метки с номерами 2, 3, 4… по порядку.
  3. Подписи не нужны — метки просто нумеруются, а студент отвечает на вопросы по номерам.

5.3 Как удалить метку

  • Просто кликните по метке — она удалится. Оставшиеся метки перенумеруются автоматически.
📌 Важно: Метки привязываются к самому изображению, а не к контейнеру. Поэтому они не смещаются при изменении размера окна, на разных экранах и в экспортированном HTML.
💡 Совет: Ставьте метки точно на структуры. Если промахнулись — удалите и поставьте заново. Точность важна, потому что студент будет отвечать по номерам.

5.4 Как использовать метки в вопросах

Типичный сценарий: загружаете схему сердца с пронумерованными структурами (или ставите метки сами), а затем создаёте вопросы вида:

  • «Что обозначено меткой 1?» → варианты ответов.
  • «Какая структура отмечена меткой 3?» → варианты ответов.

6. Предпросмотр глазами студента

Перед экспортом обязательно проверьте тест в режиме просмотра. Это покажет, как его увидит студент.

6.1 Как открыть просмотр

  1. Убедитесь, что добавлен хотя бы один вопрос.
  2. Нажмите кнопку «👁️ Просмотр» в шапке.
  3. Откроется вкладка «Предпросмотр» с тестом.

6.2 Что проверять

  • Текст вопросов — нет ли опечаток, понятны ли формулировки.
  • Варианты ответов — нет ли дублей, корректен ли правильный.
  • Изображения и метки — видны ли, не смещаются ли при сужении окна.
  • Типы вопросов — работают ли текстовый ввод, сопоставление, множественный выбор.
📌 Важно: В предпросмотре таймер не работает — это сделано, чтобы вы могли спокойно проверить тест. Таймер включится только в экспортированном HTML.

6.3 Режим «Показывать правильный ответ сразу»

Если в настройках включена опция «Показывать правильный ответ после каждого вопроса», то поведение теста меняется:

  • Включено — студент отвечает на вопрос, сразу видит результат: правильно/неправильно, и какой ответ был верным. Удобно для обучающих тестов и самопроверки.
  • Выключено — студент отвечает на все вопросы подряд, а разбор видит только после завершения теста. Подходит для контрольных и экзаменационных тестов.
📌 Важно: В экспортированном HTML-файле эта опция сохраняется и работает так же, как в предпросмотре.

6.4 Что видит студент после завершения

  • Процент выполнения и количество набранных баллов.
  • Пометку «✅ Тест пройден» или «❌ Тест не пройден» по порогу.
  • Разбор ответов — где ошибся, какой ответ правильный, пояснение.

7. Экспорт HTML и JSON

В конструкторе предусмотрено два формата сохранения: HTML — для студентов, JSON — для преподавателя (для дальнейшего редактирования).

7.1 Экспорт HTML (для студентов)

  1. Убедитесь, что тест готов и проверен в просмотре.
  2. Нажмите кнопку «📤 Экспорт HTML» в шапке.
  3. Скачается файл с названием теста, например Анатомия_сердца_КРС.html.
📌 Важно: Готовый HTML-файл автономен — изображения встроены внутрь, ничего дополнительно скачивать не нужно. Он работает офлайн в любом современном браузере.

7.2 Что умеет экспортированный тест

  • Стартовый экран с описанием и кнопкой «Начать тест».
  • Таймер — если задано ограничение по времени.
  • Автоматическая проверка — после завершения студент видит результат.
  • Режим мгновенной проверки — если в настройках включена опция «Показывать правильный ответ после каждого вопроса», студент видит результат сразу после ответа.
  • Разбор ответов — какие верные, какие нет, с пояснениями.
  • Кнопка «Пройти заново» — для повторного прохождения.

7.3 Сохранение JSON (для преподавателя)

  1. Нажмите кнопку «💾 JSON» в шапке.
  2. Скачается файл с расширением .json — в нём весь тест: вопросы, ответы, изображения, настройки.
  3. Для загрузки — нажмите «📂 Загрузить» и выберите сохранённый файл.
💡 Совет: Храните JSON-файлы как резервные копии. Если браузер очистит localStorage, вы восстановите тест из JSON. Также удобно переносить тест между компьютерами.

Пример 1: Тест по анатомии «Строение сердца собаки»

📘 Настройка теста

Дисциплина: Анатомия
Время: 10 мин
Проходной балл: 70%
Перемешивать: вопросы — да, ответы — да

Вопросы:

  • Одиночный + изображение. «Что обозначено меткой 1?» → Левое предсердие / Правый желудочек / Аорта / Лёгочная артерия. Правильный: Левое предсердие.
  • Множественный. «Выберите структуры, относящиеся к правому отделу сердца» → Правый желудочек, Правое предсердие, Трёхстворчатый клапан, Аорта.
  • Текстовый. «Сколько камер в сердце собаки?» → 4.
  • Сопоставление. Левое предсердие → Из лёгочных вен, Правый желудочек → В лёгочную артерию.

Название: Антибиотики: механизмы и показания
Дисциплина: Фармакология
Время: 15 мин
Перемешивать: вопросы — да, ответы — да

Вопросы:

  • Множественный. «Выберите препараты, активные против анаэробов» → Метронидазол, Клиндамицин, Гентамицин.
  • Текстовый. «Антидот при отравлении аминогликозидами?» → нет / симптоматическая терапия.
  • Сопоставление. Гентамицин → нефротоксичность, Тетрациклин → нарушение зубной эмали, Хлорамфеникол → апластическая анемия.

  • Текстовый. «Как называется затемнение в лёгком?» → инфильтрат / пневмония / очаг.

9. Частые вопросы (FAQ)

❓ Что делать, если браузер очистил данные?

Загрузите ранее сохранённый JSON-файл кнопкой «📂 Загрузить». Поэтому важно периодически сохранять JSON как резервную копию.

❓ Можно ли редактировать уже сохранённый тест?

Да. Сохраните тест в JSON, откройте его кнопкой «📂 Загрузить», внесите изменения, снова сохраните. Так можно вести версии теста.

❓ Как сделать несколько правильных ответов в одиночном вопросе?

Никак — одиночный тип предполагает строго один правильный. Если нужно несколько, выбирайте тип «Множественный выбор».

❓ Что делать, если метка стоит не на месте?

Кликните по ней — она удалится. Поставьте новую метку в нужное место. Номера остальных меток перенумеруются автоматически.

❓ Изображение слишком большое и не влезает в поле?

Оно автоматически масштабируется под ширину контейнера с сохранением пропорций. Метки при этом не смещаются — они привязаны к самому изображению.

❓ Работает ли тест без интернета?

Да, экспортированный HTML-файл полностью автономен. Открывается двойным кликом в любом браузере, интернет не нужен.

❓ Чем отличается «Показывать правильный ответ после каждого вопроса»?

Если опция включена, студент сразу после ответа на вопрос видит, правильно он ответил или нет, и какой ответ был верным. Если выключена — проверка происходит только после завершения всего теста. Для обучающих тестов лучше включать, для контрольных — выключать.

❓ Что делать, если студент не успел за отведённое время?

По истечении таймера тест автоматически завершается, и студент видит результат по тем вопросам, на которые успел ответить.

⚠️ Важно: Не удаляйте вкладку браузера во время создания теста без предварительного сохранения JSON. Хотя данные сохраняются в localStorage, при очистке браузера они могут исчезнуть.

Конструктор тестов — это универсальный инструмент, который превращает проверку знаний в интерактивный и автоматизированный процесс.

Ключевые преимущества:

  • 4 типа вопросов — одиночный, множественный, текстовый, сопоставление.
  • Работа с изображениями — метки с автонумерацией, без смещения на разных экранах.
  • Гибкая настройка — время, проходной балл, перемешивание, автор, дисциплина.
  • Два формата экспорта — HTML для студентов, JSON для преподавателя.
  • Автономность — работает офлайн в любом браузере.
  • Автоматическая проверка — студент сразу видит результат и разбор.
