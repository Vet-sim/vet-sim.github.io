1. Что такое Хронология / Последовательность

Конструктор «Хронология / Последовательность» — это инструмент для создания упражнений на упорядочивание. Он решает несколько задач преподавателя:

  • Отработка алгоритмов — студент запоминает правильную последовательность действий.
  • Понимание процессов — помогает увидеть причинно-следственные связи и этапы.
  • Развитие логики — тренирует аналитическое мышление.
  • Визуализация — шаги можно сопровождать текстом и изображениями.

3. Создание последовательности

Последовательность состоит из шагов, которые студент должен расположить в правильном порядке.

3.1 Как добавить шаг

  1. Нажмите кнопку «➕ Добавить шаг».
  2. Введите текст шага (до 200 символов).
  3. При необходимости загрузите изображение для шага.
  4. Нажмите «Сохранить».

3.2 Порядок шагов

  • По умолчанию шаги добавляются в порядке их создания.
  • Вы можете перетаскивать шаги в списке, чтобы изменить их порядок.
  • Порядок шагов в конструкторе — это правильный ответ.
💡 Совет: Задавайте чёткие и короткие названия шагов (3-5 слов). Это облегчает восприятие и перетаскивание.

4. Редактирование и управление шагами

4.1 Как редактировать шаг

  • Нажмите на шаг в списке.
  • Измените текст или загрузите новое изображение.
  • Нажмите «Сохранить».

4.2 Как удалить шаг

  • Нажмите значок 🗑️ рядом с шагом в списке.
  • Подтвердите удаление.

5. Сохранение и загрузка проекта

Вы можете сохранить проект и продолжить работу позже.

5.1 Сохранение проекта

  • Нажмите кнопку «💾 Сохранить проект».
  • Скачайте файл с расширением .json.
  • Этот файл содержит все данные о последовательности.

5.2 Загрузка проекта

  • Нажмите кнопку «📂 Загрузить проект».
  • Выберите ранее сохранённый файл .json.
  • Последовательность восстановится в том виде, в котором вы её сохранили.
📌 Важно: Сохраняйте проект после каждого изменения, чтобы не потерять работу.

6. Режим студента

В режиме студента упражнение становится интерактивным.

6.1 Что видит студент

  • Инструкцию к заданию.
  • Список шагов в случайном порядке.
  • Поле для перетаскивания — сюда студент перемещает шаги.
  • Кнопку проверки — для самопроверки.

6.2 Как работает проверка

  • Студент перетаскивает шаги в нужном порядке.
  • Нажимает «Проверить».
  • Правильно расположенные шаги подсвечиваются зелёным.
  • Неправильно — красным, с подсказкой.
📌 Важно: Проверка работает автоматически, что делает задание самодостаточным для самостоятельной работы.

7. Экспорт упражнения

Готовое упражнение можно экспортировать в автономный HTML-файл.

7.1 Как экспортировать

  1. Убедитесь, что все шаги добавлены и настроены.
  2. Нажмите кнопку «📤 Экспорт».
  3. Скачайте файл sequence.html.

7.2 Что получает студент

  • Один HTML-файл — всё встроено, ничего не нужно скачивать дополнительно.
  • Интерактивное упражнение с перетаскиванием.
  • Автоматическая проверка — мгновенная обратная связь.
  • Работает офлайн — открывается в любом браузере без интернета.
📌 Важно: Файл работает в любом современном браузере (Chrome, Edge, Firefox). Для открытия достаточно двойного клика по файлу.

8. Практические примеры

Пример 1: Этапы оказания первой помощи при кровотечении

📘 Последовательность шагов (правильный порядок)

Шаг 1: Оценить состояние пациента (сознание, дыхание).
Шаг 2: Вызвать ветеринара или скорую помощь.
Шаг 3: Наложить давящую повязку или жгут (при артериальном кровотечении).
Шаг 4: Приподнять конечность (если возможно).
Шаг 5: Контролировать состояние до прибытия врача.

Цель: Закрепить алгоритм действий при неотложном состоянии.

Пример 2: Патогенез пироплазмоза у собак

📘 Последовательность шагов (правильный порядок)

Шаг 1: Укус иксодового клеща.
Шаг 2: Попадание паразитов (Babesia) в кровь.
Шаг 3: Внедрение в эритроциты и их разрушение.
Шаг 4: Гемолиз → гемоглобинурия, анемия.
Шаг 5: Развитие клинических симптомов (лихорадка, слабость, желтуха).

Цель: Понять последовательность развития заболевания.

Пример 3: Алгоритм диагностики

📘 Последовательность шагов (правильный порядок)

Шаг 1: Сбор анамнеза.
Шаг 2: Клинический осмотр.
Шаг 3: Назначение лабораторных анализов.
Шаг 4: Интерпретация результатов.
Шаг 5: Постановка диагноза.

Цель: Закрепить алгоритм диагностического поиска.

9. Частые вопросы (FAQ)

❓ Сколько шагов можно добавить?

Количество шагов не ограничено. Рекомендуется 5-8 шагов для поддержания внимания и простоты восприятия.

❓ Можно ли использовать изображения в шагах?

Да, вы можете загружать изображения для каждого шага. Это помогает визуализировать процесс.

❓ Работает ли упражнение без интернета?

Да, готовый HTML-файл работает полностью офлайн.

❓ Можно ли изменить порядок шагов после создания?

Да, вы можете перетаскивать шаги в списке в любое время.

⚠️ Важно: При создании упражнения убедитесь, что порядок шагов в конструкторе соответствует правильному ответу. Студент будет видеть шаги в случайном порядке и должен восстановить ваш порядок.

🎯 Заключение

Конструктор «Хронология / Последовательность» — это инструмент, который превращает запоминание алгоритмов и процессов в интерактивное упражнение на логику.

Ключевые преимущества:

  • Понимание процесса — студент видит логику шагов.
  • Интерактивность — перетаскивание активирует моторную память.
  • Автоматическая проверка — мгновенная обратная связь.
  • Гибкость — подходит для любых дисциплин.
  • Офлайн-доступность — не нужен интернет.

💡 Совет: Начните с создания последовательности из 4-5 шагов для простого процесса (например, алгоритма оказания первой помощи). Постепенно усложняйте, добавляя больше шагов и изображений.
