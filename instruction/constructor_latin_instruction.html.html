1. Что такое Veterinaria Latina

Veterinaria Latina — это специализированный конструктор для работы с латинской терминологией в ветеринарном образовании. Он помогает:

  • Преподавателям — быстро создавать словари по разным темам (анатомия, фармакология, патология) и экспортировать готовые тренажёры.
  • Студентам — отрабатывать навыки определения склонения, правильного окончания и формы родительного падежа.
  • Автоматизировать проверку — мгновенная обратная связь показывает ошибки и правильные ответы.
📌 Важно: Латинская терминология — основа профессионального языка ветеринарного врача. Правильное использование падежей и склонений критично для точного понимания анатомических и клинических терминов.

💡 Совет: Начните с загрузки примера (кнопка «📂 Загрузить пример»), чтобы увидеть, как работает конструктор. Пример содержит 37 ветеринарных терминов с разными склонениями.

3. Редактор слов

3.1 Добавление слова

  1. Заполните поля формы:
    • Nom. sg. — именительный падеж (например, musculus)
    • Gen. sg. — родительный падеж (например, musculi)
    • Перевод — значение на русском (например, мышца)
    • Склонение — выберите из выпадающего списка (I–V)
  2. Нажмите «➕ Добавить».
  3. Слово появится в списке ниже.
📘 Пример добавления

Nom.: vena
Gen.: venae
Перевод: вена
Склонение: I

После добавления слово появится в словаре, и его можно использовать в тренажёре.

3.2 Редактирование и удаление

  • На карточке слова нажмите ✏️ — поля формы заполнятся данными слова. Внесите изменения и нажмите «💾 Обновить».
  • Нажмите 🗑️ на карточке слова, чтобы удалить его из словаря.

3.3 Дополнительные функции

  • «📂 Загрузить пример» — загружает демонстрационный набор из 37 ветеринарных терминов.
  • «🗑️ Очистить всё» — удаляет все слова из словаря.
  • Список слов автоматически сохраняется в localStorage браузера. При следующем открытии словарь восстановится.
⚠️ Важно: При загрузке примера текущий словарь будет заменён. Если у вас есть важные данные, предварительно экспортируйте их в JSON.

4. Тренажёр

Вкладка «Тренажёр» предлагает интерактивный способ проверки знаний. Студент должен определить три параметра для каждого слова:

Шаг Что нужно сделать Как оценивается
1. Склонение Выбрать правильное склонение (I–V) Проверяется соответствие выбранного склонения
2. Окончание Gen. sg. Выбрать правильное окончание для родительного падежа Проверяется соответствие окончания склонению
3. Форма Gen. sg. Ввести форму родительного падежа в текстовое поле Сравнивается с правильным ответом (регистр не важен)

4.1 Как проходить тренажёр

  1. В центре экрана отображается слово в именительном падеже и его перевод.
  2. Выберите склонение из пяти вариантов (I–V).
  3. Выберите правильное окончание для Gen. sg. из пяти вариантов.
  4. Введите форму родительного падежа в текстовое поле.
  5. Нажмите «✅ Проверить».
  6. Получите обратную связь: правильный ответ или список ошибок.
  7. Нажмите «➡️ Следующее слово» для продолжения.
📘 Пример работы тренажёра

Слово: canis (собака)
Правильный ответ: III склонение, окончание -is, Gen. sg. canis
Ошибка студента: выбрал II склонение, окончание -i, ввёл cani
Обратная связь: ❌ Ошибка: склонение, окончание, форма Gen. sg. Правильно: canis → canis (III склонение, окончание -is)

4.2 Статистика и навигация

  • Вверху отображается прогресс (номер текущего слова из общего количества).
  • Справа — счёт (правильные ответы из общего числа попыток).
  • Кнопка «🔄 Сбросить» обнуляет счёт и начинает с первого слова.
💡 Совет для студентов: Не торопитесь. Сначала вспомните склонение по окончанию Nom. sg., затем подберите правильное окончание. Только после этого вводите форму родительного падежа.

5. Экспорт и импорт

Вкладка «Экспорт» позволяет управлять данными словаря и создавать готовые тренажёры для студентов.

5.1 Экспорт в HTML (готовый тренажёр)

  • Нажмите «📤 Экспортировать HTML».
  • Скачается самостоятельный HTML-файл с тренажёром.
  • Файл содержит все слова из вашего словаря и работает полностью офлайн.
  • Студент может открыть его в браузере и сразу начать тренировку.
📌 Важно: Экспортированный HTML-файл включает все слова, но не требует интернета для работы. Идеально для отправки студентам по электронной почте или через облачные сервисы.

5.2 Экспорт и импорт JSON

  • «📄 Экспорт JSON» — сохраняет словарь в формате JSON для резервного копирования.
  • «📂 Импорт JSON» — загружает словарь из JSON-файла.
  • JSON-данные отображаются в текстовом поле, их можно копировать или редактировать вручную.
📘 Пример JSON-структуры
[
    {
        "nom": "canis",
        "gen": "canis",
        "trans": "собака",
        "decl": "III"
    },
    {
        "nom": "felis",
        "gen": "felis",
        "trans": "кошка",
        "decl": "III"
    }
]
⚠️ Важно: При импорте JSON текущий словарь будет заменён. Предварительно экспортируйте данные, если они вам нужны.

7. Частые вопросы (FAQ)

❓ Сколько слов можно добавить в словарь?

Количество слов не ограничено. Вы можете добавлять столько терминов, сколько нужно для вашего курса.

❓ Что делать, если я случайно удалил слова?

Нажмите кнопку «📂 Загрузить пример», чтобы восстановить демонстрационный набор. Если у вас был экспортирован JSON, импортируйте его.

❓ Работает ли тренажёр на телефоне?

Да, интерфейс полностью адаптивен. Кнопки и поля ввода оптимизированы для работы на мобильных устройствах.

❓ Могу ли я редактировать экспортированный HTML-файл?

Да, экспортированный файл — это обычный HTML. Вы можете открыть его в любом текстовом редакторе и внести изменения при необходимости.

❓ Сохраняются ли мои данные после закрытия браузера?

Да, словарь автоматически сохраняется в localStorage браузера. При следующем открытии конструктора данные восстановятся.

❓ Что означают ошибки в тренажёре?

При проверке выделяются три параметра: склонение, окончание и форма Gen. sg. Если параметр выбран неверно, он отображается в списке ошибок. В обратной связи показывается правильный ответ.

💡 Совет преподавателям: Начните с малого — создайте словарь из 5–10 слов по конкретной теме и дайте студентам для тренировки. Постепенно расширяйте словарь по мере изучения новых тем.
