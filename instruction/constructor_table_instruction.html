Добро пожаловать! Конструктор табличных заданий — это инструмент для создания интерактивных таблиц, где студенты заполняют поля и выбирают варианты из выпадающих списков. Это идеальный формат для систематизации знаний, сравнительных таблиц и отработки терминологии в структурированном виде.

1. Что такое табличные задания

  • Сравнение объектов — удобно сравнивать свойства и характеристики.
  • Отработка терминологии — заполнение пропусков помогает запоминать термины.
  • Развитие внимания — поиск правильного варианта в списке тренирует внимание.

3. Создание и настройка таблицы

По умолчанию создаётся таблица с 3 строками и 5 колонками.

3.1 Редактирование заголовков

  • Кликните по ячейке с заголовком (первая строка).
  • Введите текст заголовка (например, «№», «Термин», «Описание»).
  • Нажмите «Сохранить» или Enter.

3.2 Управление строками и столбцами

  • ➕ Добавить строку — добавляет новую строку в конец таблицы.
  • ➕ Добавить столбец — добавляет новый столбец справа.
  • Удалить строку/столбец — удаляет выделенную строку или столбец.
💡 Совет: Продумайте структуру таблицы заранее. Количество строк и столбцов должно соответствовать вашему заданию.

4. Добавление текстовых полей

Текстовые поля позволяют студенту вводить свой ответ в ячейку.

4.1 Как добавить текстовое поле

  1. Выделите нужную ячейку (кликните по ней).
  2. Нажмите кнопку «✏️ Редактировать текст».
  3. Введите текст (это будет подсказка или ответ).
  4. Нажмите «Сохранить».

4.2 Использование текстовых полей

  • Подсказка: Вы можете оставить ячейку пустой (пустое поле) для самостоятельного ввода студентом.
  • Правильный ответ: Вы можете ввести правильный ответ, но студент его не увидит. При проверке система сравнит введённый студентом текст с вашим ответом.
📌 Важно: Текстовые поля чувствительны к регистру и пробелам. Рекомендуется указывать правильный ответ полностью и чётко.

5. Добавление выпадающих списков

Выпадающие списки позволяют студенту выбрать вариант из предложенных.

5.1 Как добавить выпадающий список

  1. Выделите нужную ячейку.
  2. Нажмите кнопку «📌 Вставить выпадающий список».
  3. Введите варианты через запятую (например, «бактериальное, вирусное, паразитарное»).
  4. Нажмите «Сохранить».

5.2 Как работает выпадающий список

  • Первый вариант в списке будет правильным ответом.
  • Остальные варианты — дистракторы (неправильные ответы).
  • Студент выбирает вариант из списка, и система проверяет правильность.
💡 Совет: Используйте выпадающие списки для стандартизированных ответов (например, классификации, названия групп). Для свободных ответов используйте текстовые поля.

6. Режим студента и проверка

В режиме студента таблица становится интерактивной.

6.1 Что видит студент

  • Таблицу с заголовками.
  • Текстовые поля — пустые ячейки для ввода.
  • Выпадающие списки — для выбора варианта.
  • Кнопку проверки — для самопроверки.

6.2 Как работает проверка

  • Студент заполняет все поля и выбирает варианты.
  • Нажимает «Проверить».
  • Правильные ответы подсвечиваются зелёным.
  • Неправильные — красным, с подсказкой (отображается правильный ответ).
📌 Важно: Проверка работает автоматически, что делает задание самодостаточным для самостоятельной работы.

7. Экспорт задания

Готовое задание можно экспортировать в автономный HTML-файл.

7.1 Как экспортировать

  1. Убедитесь, что таблица полностью настроена.
  2. Нажмите кнопку «📤 Экспорт».
  3. Скачайте файл table_task.html.

7.2 Что получает студент

  • Один HTML-файл — всё встроено, ничего не нужно скачивать дополнительно.
  • Интерактивная таблица для заполнения.
  • Автоматическая проверка — мгновенная обратная связь.
  • Работает офлайн — открывается в любом браузере без интернета.
📌 Важно: Файл работает в любом современном браузере (Chrome, Edge, Firefox). Для открытия достаточно двойного клика по файлу.

9. Частые вопросы (FAQ)

❓ Сколько строк и столбцов можно добавить?

Количество не ограничено. Оптимально — до 5-6 колонок и до 10 строк, чтобы таблица не была перегружена.

❓ Можно ли комбинировать текстовые поля и выпадающие списки?

Да, вы можете настроить каждую ячейку индивидуально: оставить пустой, добавить текст, вставить выпадающий список.

❓ Работает ли задание без интернета?

Да, готовый HTML-файл работает полностью офлайн.

❓ Как изменить правильный ответ в выпадающем списке?

Правильным ответом всегда считается первый вариант в списке. Чтобы изменить правильный ответ, отредактируйте список, переместив нужный вариант на первое место.

⚠️ Важно: Убедитесь, что вы правильно указали правильные ответы для текстовых полей и порядок вариантов в выпадающих списках. Это критично для корректной проверки.
