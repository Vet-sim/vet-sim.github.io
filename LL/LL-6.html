📖 Признаки III склонения
Главный признак: Gen. sing. = -is для всех существительных III склонения, независимо от рода.

Примеры

  • canis, is, mf — собака
  • pulmo, onis, m — лёгкое
  • caput, itis, n — голова
  • os, ossis, n — кость

Особенность

Nom. sing. может иметь разные окончания. Определять склонение нужно по Gen. sing., а не по Nom. sing.

📌 Определение основы
Основа определяется по форме Gen. sing. путём отбрасывания окончания -is.

Примеры основ

  • radix, radicis, f → основа radic-
  • corpus, corporis, n → основа corpor-
  • tendo, tendinis, m → основа tendin-
  • caput, capitis, n → основа capit-

Важно

Основа может отличаться от формы Nom. sing.. Например: corpus → corpor-.
