Добро пожаловать! Конструктор схем связей (интеллект-карт) — это инструмент, который позволяет визуализировать сложные взаимосвязи между понятиями, процессами, симптомами, патогенезом и другими элементами в ветеринарии. Вы создаёте узлы (понятия) и соединяете их связями, формируя логическую схему.

💡 Главная идея: Вы создаёте схему, где каждый узел — это понятие (симптом, болезнь, этап лечения), а связи описывают отношения между ними (вызывает, приводит к, усиливает, блокирует и т.д.). Это помогает студентам видеть целостную картину патологического процесса или алгоритма действий.

1. Что такое Конструктор схем связей

Конструктор схем связей — это инструмент для создания визуальных интеллект-карт и схем патогенеза. Он решает несколько задач преподавателя:

  • Визуализация сложных процессов — студент видит цепочку событий (патогенез, лечение).
  • Понимание связей — студент запоминает не изолированные факты, а их взаимосвязи.
  • Создание алгоритмов — пошаговые схемы диагностики или лечения.
  • Интерактивность — студент может исследовать схему, кликая на узлы и связи.

3. Добавление узлов

Узлы — это основные элементы схемы (понятия, симптомы, этапы, факторы).

3.1 Как добавить узел

  1. Нажмите кнопку «➕ Добавить узел».
  2. Введите название узла (например, «Гипоксия», «Ацидоз», «Антибиотики»).
  3. При необходимости добавьте описание или примечание (до 200 символов).
  4. Нажмите «Сохранить».
💡 Совет: Называйте узлы кратко и ёмко, чтобы они легко читались на схеме. Для описания используйте поле «Примечание».

4. Создание связей

Связи описывают отношения между узлами.

4.1 Как добавить связь

  1. Нажмите кнопку «🔗 Добавить связь».
  2. Выберите исходный узел (откуда идёт связь).
  3. Выберите конечный узел (куда идёт связь).
  4. Введите тип связи (например, «вызывает», «приводит к», «усиливает», «блокирует»).
  5. Нажмите «Сохранить».
📘 Пример связи

Исходный узел: Недостаток энергии
Конечный узел: Мобилизация жира
Тип связи: вызывает

5. Управление узлами и связями

5.1 Редактирование

  • В списке узлов/связей найдите нужный элемент.
  • Нажмите на значок ✏️.
  • Измените данные и сохраните.

5.2 Удаление

  • Нажмите значок 🗑️ рядом с узлом или связью.
  • Подтвердите удаление.
⚠️ Важно: При удалении узла все связи, связанные с ним, также удаляются автоматически.

6. Визуализация и настройка схемы

Схема автоматически визуализируется по мере добавления узлов и связей. Вы можете настраивать её отображение:

Настройка Что делает Как использовать
Масштаб Увеличивает или уменьшает схему Используйте колесико мыши или кнопки «+»/«-»
Цвет узлов Выделение групп Назначьте разные цвета для разных типов узлов (симптомы, причины, лечение)
Тип линий Визуальное различие связей Используйте сплошные, пунктирные или цветные линии для разных типов отношений
📌 Важно: Настройки визуализации помогают сделать схему более наглядной и удобной для восприятия студентами.

7. Экспорт схемы

Готовую схему можно экспортировать в автономный HTML-файл.

7.1 Как экспортировать

  1. Убедитесь, что схема завершена и все связи корректны.
  2. Нажмите кнопку «📤 Экспорт».
  3. Скачайте файл schema.html.

7.2 Что получает студент

  • Один HTML-файл — всё встроено, ничего не нужно скачивать дополнительно.
  • Интерактивная схема — можно приближать, перемещать, кликать на узлы для просмотра описаний.
  • Работает офлайн — открывается в любом браузере без интернета.
📌 Важно: Файл работает в любом современном браузере (Chrome, Edge, Firefox). Для открытия достаточно двойного клика по файлу.

8. Практические примеры

Пример 1: Патогенез кетоза у коров

📘 Схема (пример из конструктора)

Узлы:

  • Недостаток энергии
  • Мобилизация жира
  • ↑ Кетоновые тела
  • Снижение аппетита
  • Потеря веса
  • Жировая дистрофия печени

Связи:

  • Недостаток энергии → Мобилизация жира (вызывает)
  • Мобилизация жира → ↑ Кетоновые тела (приводит к)
  • ↑ Кетоновые тела → Снижение аппетита (вызывает)
  • ↑ Кетоновые тела → Потеря веса (приводит к)
  • ↑ Кетоновые тела → Жировая дистрофия печени (вызывает)
  • Снижение аппетита → Потеря веса (усиливает)

Пример 2: Алгоритм диагностики

📘 Состав схемы

Узлы:

  • Симптомы (лихорадка, анорексия)
  • Сбор анамнеза
  • Клинический осмотр
  • Лабораторные анализы
  • Дифференциальный диагноз
  • Окончательный диагноз

Связи:

  • Симптомы → Сбор анамнеза (переход)
  • Сбор анамнеза → Клинический осмотр (переход)
  • Клинический осмотр → Лабораторные анализы (переход)
  • Лабораторные анализы → Дифференциальный диагноз (переход)
  • Дифференциальный диагноз → Окончательный диагноз (переход)

9. Частые вопросы (FAQ)

❓ Сколько узлов можно добавить?

Количество узлов не ограничено. Рекомендуется для наглядности использовать 5–15 узлов.

❓ Можно ли использовать одинаковые типы связей?

Да, вы можете использовать любые типы связей. Главное — чтобы они логично описывали отношения между узлами.

❓ Работает ли схема без интернета?

Да, готовый HTML-файл работает полностью офлайн.

❓ Можно ли импортировать схему из другого формата?

На данный момент импорт не поддерживается. Схему нужно создавать заново в конструкторе.

⚠️ Важно: При создании схемы избегайте циклов (узлы, ссылающиеся друг на друга), если это не предусмотрено вашей логикой. Схема должна быть понятной и читаемой.

🎯 Заключение

Конструктор схем связей — это инструмент, который превращает сложные взаимосвязи в наглядную и понятную схему.

Ключевые преимущества:

  • Визуализация — сложные процессы становятся понятными.
  • Структурирование — информация упорядочивается и запоминается лучше.
  • Интерактивность — студент может исследовать схему.
  • Офлайн-доступность — не нужен интернет.
  • Гибкость — подходит для любых дисциплин и процессов.

💡 Совет: Начните с построения простой схемы патогенеза одного заболевания. Затем используйте этот опыт для создания более сложных алгоритмов.
