1. Что такое «Соедини термин»

Конструктор «Соедини термин с определением» — это инструмент для создания упражнений на ассоциативную память. Он решает несколько задач преподавателя:

  • Запоминание терминологии — связь понятия и его определения.
  • Развитие мышления — поиск правильной пары.
  • Интерактивность — перетаскивание карточек активирует моторную память.
  • Геймификация — процесс соединения карточек воспринимается как игра.

3. Создание пар

3.1 Как добавить пару

  1. Введите термин в левое поле (например, «Пальпация»).
  2. Введите определение в правое поле (например, «Метод обследования с помощью ощупывания»).
  3. Нажмите «➕ Добавить пару».
  4. Пара появится в списке ниже.

3.2 Рекомендации по созданию пар

  • Термины должны быть краткими и чёткими (одно слово или короткое словосочетание).
  • Определения должны быть точными и однозначными.
  • Старайтесь, чтобы определения не пересекались и не допускали неоднозначного толкования.

3.3 Управление парами

  • Редактирование: Нажмите на пару в списке, измените текст и сохраните.
  • Удаление: Нажмите значок 🗑️ рядом с парой.
💡 Совет: Начните с 4-6 пар. Это оптимальное количество для быстрого и эффективного запоминания.

4. Режим студента

В режиме студента карточки становятся интерактивными.

4.1 Что видит студент

  • Карточки с терминами (в случайном порядке).
  • Карточки с определениями (в случайном порядке).
  • Инструкцию к заданию.
  • Кнопку проверки — для самопроверки.

4.2 Как работает соединение

  • Студент перетаскивает карточку с определением к соответствующему термину (или наоборот).
  • Правильные пары подсвечиваются.
  • После соединения всех пар студент нажимает «Проверить».
  • Правильные пары подсвечиваются зелёным.
  • Неправильные — красным, с отображением правильного ответа.
📌 Важно: Проверка работает автоматически, что делает задание самодостаточным для самостоятельной работы.

5. Экспорт задания

Готовое задание можно экспортировать в автономный HTML-файл.

5.1 Как экспортировать

  1. Убедитесь, что все пары созданы.
  2. Нажмите кнопку «📤 Экспорт».
  3. Скачайте файл terminy_trainer.html.

5.2 Что получает студент

  • Один HTML-файл — всё встроено, ничего не нужно скачивать дополнительно.
  • Интерактивное упражнение с перетаскиванием карточек.
  • Автоматическая проверка — мгновенная обратная связь.
  • Работает офлайн — открывается в любом браузере без интернета.
📌 Важно: Файл работает в любом современном браузере (Chrome, Edge, Firefox). Для открытия достаточно двойного клика по файлу.

7. Частые вопросы (FAQ)

❓ Сколько пар можно добавить?

Количество пар не ограничено. Рекомендуется 4-8 пар для оптимальной нагрузки.

❓ Можно ли использовать изображения?

На данный момент конструктор поддерживает только текстовые пары.

❓ Работает ли упражнение без интернета?

Да, готовый HTML-файл работает полностью офлайн.

❓ Как студент может узнать правильный ответ?

После нажатия «Проверить» неправильные пары подсвечиваются красным, а правильные — зелёным, с отображением правильного ответа.

⚠️ Важно: Убедитесь, что определения уникальны и однозначно соответствуют только одному термину. Иначе студент не сможет выполнить задание корректно.
