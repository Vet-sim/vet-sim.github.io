1. Что такое Сортировка по категориям

  • Развитие аналитического мышления — поиск общих признаков и различий.
  • Визуализация связей — наглядное представление структуры знаний.
  • Интерактивность — перетаскивание активирует моторную память.

3. Создание категорий

Категории — это группы, в которые студент будет распределять элементы.

3.1 Как добавить категорию

  1. Нажмите кнопку «➕ Добавить категорию».
  2. Введите название категории (например, «Бактериальные болезни», «Вирусные болезни»).
  3. Нажмите «Сохранить».

3.2 Рекомендации по количеству категорий

  • Оптимальное количество категорий — от 2 до 5.
  • Слишком много категорий может запутать студента.
  • Категории должны быть чёткими и не пересекаться.

4. Добавление элементов

Элементы — это объекты (термины, названия, понятия), которые студент должен распределить по категориям.

4.1 Как добавить элемент

  1. Нажмите кнопку «➕ Добавить элемент».
  2. Введите название элемента (например, «Сальмонеллёз», «Бешенство»).
  3. Выберите правильную категорию для этого элемента из выпадающего списка.
  4. Нажмите «Сохранить».

4.2 Рекомендации по количеству элементов

  • Рекомендуемое количество элементов — от 6 до 15.
  • Элементы должны быть чёткими и однозначными.
  • Старайтесь, чтобы количество элементов в разных категориях было примерно одинаковым.
📌 Важно: Каждый элемент должен быть привязан к одной категории. Дублирование элементов не допускается.

5. Управление категориями и элементами

5.1 Редактирование

  • Нажмите на категорию или элемент в списке.
  • Измените название или, для элемента, измените категорию.
  • Нажмите «Сохранить».

5.2 Удаление

  • Нажмите значок 🗑️ рядом с категорией или элементом.
  • Подтвердите удаление.
⚠️ Важно: При удалении категории все элементы, привязанные к ней, также удаляются. Будьте осторожны.

6. Режим студента

В режиме студента упражнение становится интерактивным.

6.1 Что видит студент

  • Инструкцию к заданию.
  • Категории (пустые контейнеры для сортировки).
  • Пул элементов — все элементы в случайном порядке.
  • Кнопку проверки — для самопроверки.

6.2 Как работает сортировка

  • Студент перетаскивает элементы из общего пула в нужные категории.
  • В каждой категории собираются соответствующие элементы.
  • Если элемент не подходит ни к одной категории, он остаётся в пуле.
  • Нажимает «Проверить».
  • Правильно распределённые элементы подсвечиваются зелёным.
  • Неправильно — красным, с подсказкой.
📌 Важно: Проверка работает автоматически, что делает задание самодостаточным для самостоятельной работы.

7. Экспорт упражнения

Готовое упражнение можно экспортировать в автономный HTML-файл.

7.1 Как экспортировать

  1. Убедитесь, что все категории и элементы добавлены.
  2. Нажмите кнопку «📤 Экспорт».
  3. Скачайте файл sorting.html.

7.2 Что получает студент

  • Один HTML-файл — всё встроено, ничего не нужно скачивать дополнительно.
  • Интерактивное упражнение с перетаскиванием.
  • Автоматическая проверка — мгновенная обратная связь.
  • Работает офлайн — открывается в любом браузере без интернета.
📌 Важно: Файл работает в любом современном браузере (Chrome, Edge, Firefox). Для открытия достаточно двойного клика по файлу.

9. Частые вопросы (FAQ)

❓ Сколько категорий и элементов можно добавить?

Количество не ограничено. Рекомендуется 2-5 категорий и 6-15 элементов для удобства восприятия.

❓ Можно ли использовать изображения в элементах?

На данный момент конструктор поддерживает только текстовые элементы.

❓ Работает ли упражнение без интернета?

Да, готовый HTML-файл работает полностью офлайн.

❓ Как изменить категорию для элемента?

Отредактируйте элемент и выберите другую категорию из выпадающего списка.

⚠️ Важно: Убедитесь, что каждый элемент привязан к правильной категории. Иначе студент не сможет выполнить задание корректно.

Конструктор «Сортировка по категориям» — это инструмент, который превращает запоминание классификаций в интерактивное упражнение на логику.

Ключевые преимущества:

  • Запоминание классификаций — структурирование знаний.
  • Развитие аналитического мышления — поиск общих признаков.
  • Интерактивность — перетаскивание активирует моторную память.
  • Автоматическая проверка — мгновенная обратная связь.
  • Гибкость — подходит для любых дисциплин.
  • Офлайн-доступность — не нужен интернет.

💡 Совет: Начните с 2-3 категорий и 5-6 элементов. Проведите тестирование на коллегах или студентах, чтобы убедиться, что категории чётко определены.
