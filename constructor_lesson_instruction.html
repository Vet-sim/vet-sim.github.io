Конструктор занятия (урока) — это инструмент, который позволяет собрать несколько учебных материалов (текст, видео, PDF, изображения, тренажёры, EXE-программы, интерактивы и задания) в один готовый HTML-файл. 1. Что такое конструктор занятия

Конструктор занятия — это инструмент для быстрой сборки учебных материалов в один файл. Он решает несколько проблем преподавателя:

  • Разрозненность материалов — вместо папки с файлами вы получаете один HTML-файл.
  • Сложность навигации — студент переключается между блоками через вкладки.
  • Потеря ответов — ответы на задания сохраняются автоматически в браузере студента.
  • Зависимость от интернета — урок работает офлайн (кроме YouTube-видео).

2. Общая структура интерфейса

Конструктор состоит из нескольких ключевых зон:

Зона Что находится Действия
Шапка Название, версия, кнопки управления Сохранение, добавление блока, предпросмотр, экспорт, сброс, переключение режима
Название занятия Поле для ввода названия Введите название, которое увидят студенты
Список блоков Все добавленные блоки с их типами и названиями Перетаскивание, редактирование, удаление
Режим просмотра Постраничный просмотр готового урока Навигация по блокам, выполнение заданий

3. Типы блоков

В конструкторе доступно 8 типов блоков для разных видов учебных материалов.

Тип Иконка Что добавляет Когда использовать
Текст 📝 Произвольный текст с заголовком Объяснение, инструкции, конспект
Видео 🎬 Ссылка на YouTube, VK, Rutube Лекции, демонстрации
PDF 📄 Загрузка PDF-файла Документы, статьи, методички
Изображение 🖼️ Загрузка JPG, PNG, GIF, SVG, WEBP Схемы, рисунки, фотографии
Тренажёр ВетСим 🧩 Загрузка HTML-файла тренажёра Интерактивные задания из экосистемы ВетСим
EXE-программа ⚙️ Загрузка .exe-файла для Windows Старые обучающие программы (например, "Виртуальная физиология")
Внешний интерактив 🌐 Ссылка или iframe-код LearningApps, интерактивные карты
Задание с ответом ✏️ Текст задания + поле для ответа Самостоятельная работа, контроль
📌 Важно: Для типов «PDF», «Изображение», «Тренажёр» и «EXE» файл встраивается в HTML как Base64. Это значит, что урок работает офлайн, но размер файла увеличивается. Рекомендуемый размер каждого файла — до 20 МБ.

4. Управление блоками

4.1 Добавление блока

  1. Нажмите кнопку «➕ Добавить блок».
  2. Выберите тип блока в выпадающем списке.
  3. Заполните поля:
    • Заголовок (обязательно) — краткое название блока.
    • Содержание — текст, ссылка или загрузка файла.
    • Дополнительные настройки — аудио, таймер, баллы (опционально).
  4. Нажмите «✅ Добавить».

4.2 Изменение порядка

  • Перетащите блок за значок ⠿ (три точки) в нужное место.
  • Порядок блоков сохраняется автоматически.

4.3 Редактирование блока

  • Нажмите кнопку ✏️ на блоке.
  • Измените нужные поля в модальном окне.
  • Нажмите «💾 Сохранить».

4.4 Удаление блока

  • Нажмите кнопку 🗑️ на блоке.
  • Подтвердите удаление.
💡 Совет: Порядок блоков — это порядок, в котором студенты будут их проходить. Расположите материалы логически: от теории к практике.

5. Дополнительные настройки

Для каждого блока можно добавить дополнительные опции, которые сделают урок более интерактивным.

Настройка Иконка Что делает Как использовать
Аудио 🔊 Добавляет аудиоплеер к блоку Озвучивание текста, инструкций, аудиолекций
Таймер ⏱️ Ограничивает время выполнения блока Для заданий на скорость, контрольных работ
Макс. балл 🏆 Указывает максимальный балл за блок Для оценки выполнения задания
📘 Пример: Блок с таймером и баллами

Блок: Задание с ответом
Таймер: 120 секунд (студент должен ответить за 2 минуты)
Макс. балл: 5
Результат: В режиме просмотра студент видит обратный отсчёт. По истечении времени поле для ответа блокируется. Ответ автоматически сохраняется.

6. Режим просмотра

Режим просмотра показывает, как урок будет выглядеть для студентов. Вы можете переключаться между блоками, выполнять задания и проверять работу таймера.

6.1 Как открыть режим просмотра

  • Нажмите кнопку «👁️ Предпросмотр».
  • Или переключитесь в «📖 Режим просмотра».

6.2 Навигация

  • ◀ Назад — перейти к предыдущему блоку.
  • Вперёд ▶ — перейти к следующему блоку.
  • В центре отображается номер текущего блока.

6.3 Работа с заданиями

  • В блоках «Задание с ответом» студент вводит текст в поле.
  • Ответ сохраняется автоматически в браузере студента.
  • После завершения урока студент может скачать все свои ответы (кнопка «📥 Скачать результаты»).

6.4 Таймер

  • Если для блока установлен таймер, в правом верхнем углу отображается обратный отсчёт.
  • При истечении времени блок автоматически блокируется.
  • Студент может перейти к следующему блоку.
⚠️ Важно: Ответы сохраняются в localStorage браузера. Если студент откроет урок в другом браузере или на другом устройстве, ответы не перенесутся.

7. Экспорт урока

После того как урок собран, его можно экспортировать в автономный HTML-файл, который студенты откроют в браузере.

7.1 Как экспортировать

  1. Убедитесь, что все блоки добавлены и настроены.
  2. Нажмите кнопку «📤 Экспорт».
  3. Скачайте файл lesson.html.

7.2 Что получает студент

  • Один HTML-файл — всё встроено, ничего не нужно скачивать дополнительно.
  • Постраничная навигация — переключается между блоками.
  • Все типы контента — текст, видео, PDF, изображения, тренажёры, задания.
  • Автосохранение ответов — ответы не теряются при перезагрузке.
  • Таймеры и баллы — ограничение времени и оценка.
📌 Важно: Файл работает в любом современном браузере (Chrome, Edge, Firefox). Для открытия достаточно двойного клика по файлу.

9. Частые вопросы (FAQ)

❓ Могу ли я добавить свой HTML-тренажёр?

Да, для этого используйте тип блока «🧩 Тренажёр ВетСим». Загрузите готовый HTML-файл тренажёра, и он будет встроен в урок.

❓ Как студент может сохранить свои ответы?

Ответы сохраняются автоматически в браузере студента. В конце урока студент может нажать кнопку «📥 Скачать результаты», чтобы получить текстовый файл со всеми ответами.

❓ Работает ли урок без интернета?

Да, урок полностью работает офлайн, кроме YouTube-видео (они требуют интернета). PDF, изображения, тренажёры и EXE-файлы встроены в HTML и работают без интернета.

❓ Какой максимальный размер файла можно загрузить?

Рекомендуемый размер каждого файла — до 20 МБ. Большие файлы могут замедлить загрузку урока. Для больших файлов лучше использовать ссылки.

❓ Можно ли вставить аудио в блок?

Да, в настройках добавления блока есть поле «Аудио-файл». Загрузите MP3 или WAV, и в блоке появится аудиоплеер.

❓ Что делать, если таймер сработал раньше времени?

Таймер блокирует блок только в режиме просмотра. Вы можете отредактировать блок, изменить время таймера и заново экспортировать урок.

⚠️ Важно: EXE-файлы работают только на Windows. Студенты на Mac, Chromebook или телефонах не смогут их запустить. Для таких случаев используйте HTML5-версии.
