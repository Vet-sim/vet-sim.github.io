🔤 Блок 1. Алфавитный подход. Единицы измерения25 мин
Суть: информация измеряется через длину кода, без учёта содержания. Мы считаем, сколько символов в сообщении и сколько бит несёт каждый символ.

📚 Алфавит

Набор символов. Мощность алфавита (N) — количество символов в нём.

⚖️ Информационный вес символа (i)

Количество бит на один символ. Связь: N = 2i.

📦 Информационный объём (I)

I = K × i, где K — количество символов, i — вес одного символа.

💡 Бит

Минимальная единица. 1 бит — это информация, которую несёт один символ двоичного алфавита (N=2, i=1).

N = 2i  ·  I = K × i
N — мощность алфавита, i — вес символа (бит), K — количество символов, I — объём (бит)

🩺 Пример из ветеринарии

Текст «Карта пациента Бобик» — 20 символов. Если алфавит компьютерный (N=256, i=8 бит), то объём = 20 × 8 = 160 бит = 20 байт.

Фото рентгена (2 Мбайт) = 2 097 152 байт. Если передавать по каналу 1 Мбит/с — займёт ~16 секунд.

📊 Блок 2. Содержательный подход15 мин
Суть: информация измеряется через уменьшение неопределённости. Чем больше вариантов «снимается» — тем больше информации.

💡 Бит (содержательный)

Количество информации, которое уменьшает неопределённость в 2 раза.

🧮 Формула Хартли

2i = N, где N — количество равновероятных вариантов, i — количество информации (бит).

2i = N
N — число равновероятных вариантов, i — количество информации (бит)
Если варианты неравновероятны — используется формула Шеннона (ознакомительно). В школьном курсе — чаще Хартли.

🩺 Пример из ветеринарии

Собака заболела. Возможных диагнозов 8 (равновероятных). Сообщение «у собаки чумка» несёт 3 бита информации (2³ = 8).

Если возможных диагнозов 2 (чумка или энтерит) — сообщение несёт 1 бит (2¹ = 2).

🧩 Система

Совокупность взаимосвязанных элементов, работающих как единое целое.

Компоненты: элементы, связи, цель.

Пример: организм животного (органы, системы органов, регуляция).

🎯 Управление

Процесс воздействия на систему для достижения цели.

Схема: управляющий объект → управляемый объект → обратная связь.

Обратная связь — информация о состоянии управляемого объекта, которая поступает обратно к управляющему. Без неё управление невозможно.
🩺 Пример из ветеринарии
  • Врач (управляющий) назначает лечение (прямая связь).
  • Животное (управляемый объект) реагирует на лечение.
  • Владелец сообщает врачу: «Собаке лучше / хуже» (обратная связь).
  • Врач корректирует лечение.

Без обратной связи врач не узнает, помогает ли лечение, и не сможет его скорректировать.

💡 Вопрос для размышления

Приведите пример обратной связи в работе ветеринарного фельдшера (кроме врача и животного).

🧩 Практика: 5 задач15 мин

Задача 1. Алфавитный подход

Алфавит племенного учёта содержит 32 символа. Сколько бит несёт один символ?

Решение: N = 32. 32 = 25 → i = 5 бит.

Задача 2. Объём сообщения

Сообщение из 100 символов записано алфавитом мощностью 16. Каков объём сообщения в битах?

Решение: N = 16 → 16 = 24 → i = 4 бита. Объём = K × i = 100 × 4 = 400 бит.

Задача 3. Содержательный подход

В клинике 4 равновероятных диагноза. Сообщение «у собаки энтерит» несёт сколько бит?

Решение: 2i = 4 → i = 2 бита.

Задача 4. Единицы измерения

Сколько бит в 2 Кбайтах?

Решение: 1 Кбайт = 1024 байт = 1024 × 8 = 8192 бит. 2 Кбайт = 16384 бита.

Задача 5. Связь с ветеринарией

Врач назначил лечение. Через день владелец сообщил: «Собаке лучше». Это пример чего? Обоснуйте.

Решение: Это пример обратной связи в системе управления. Владелец сообщает врачу о состоянии животного, и врач может скорректировать лечение.
