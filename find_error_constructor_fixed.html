📌 Инструкция

1. Разметьте ошибки в редакторе (минимум 1).

2. Настройте параметры (таймер, лимит промахов).

3. Нажмите «Экспорт» — скачается файл find_error_trainer.html. Откройте его в любом браузере — студенты увидят текст, смогут кликать по ошибкам и получат результат.

4. Все данные (текст, ошибки, настройки, автор) сохраняются внутри HTML-файла. Он работает автономно, без интернета.
